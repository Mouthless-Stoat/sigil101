# Chapter 2: Hello Programming

> If you already know how to program feel free to skip this chapter. If you come from another programming language you can skim through this chapter to understand the basic of `[] gdscript` syntax.

Coding is a crucial part of making custom sigils. We will be coding in `[] gdscript` in this chapter and beyond. Normally we will run `[] gdscript` **within** Godot but this chapter we will run `[] gdscript` **outside** of Godot. In this chapter we will talk about everything you need to know to be a programmer. Feel free to look up more info about part that you don't understand like on [Stack Overflow](https://stackoverflow.com) (They don't like beginner asking question on there), you can also ask in the [IMF Discord Server](https://discord.gg/wXS2FpJpCt). In this chapter, we will cover the following:

-   **Variables**: Variables are use to store values to be reuse later.
-   **Operators**: Operators allow for computation to be done like math and comparison.
-   **Types**: Types are crucial and it define how data interact with each other.
-   **Control Flow**: Allow for changes to the flow of code.
-   **Functions**: Functions are use to group a section of code together to be reuse like variables but for code.
-   **Objects**: Objects are powerful tool that Godot is build on top of and we will learn how to utilise them.
