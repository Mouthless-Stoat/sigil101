# Chapter 1: Getting Started

This chapter will show how to install all the tool for creating custom sigils. We will download:

-   [Godot Engine](https://godotengine.org): Your main environment to write and test custom sigils.
-   [Visual Studio Code](https://code.visualstudio.com): Your main text editor to write and validate ruleset file.

Along with downloading these tools we will also look at how to use them. We will also look at other tools that might be useful when looking through the game source code. You can safely skip this section if you want

A [GitHub](https://github.com) account might also help to look for snippet of code on the fly. We assume that you have `[] View File Extension` enable if you don't know what that mean google it and come back to this guide
